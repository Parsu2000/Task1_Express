# Task 1 – Node.js & Express Setup 🚀

A simple backend service built with Node.js and Express that demonstrates setting up a basic server and exposing a GET endpoint.

---

## 📌 Project Overview
- **Project Name:** Stackly Task 1 - Express Setup
- **Environment:** Node.js
- **Framework:** Express.js
- **Config Management:** dotenv

---

## 🛠️ Features
- Loads port configuration securely using `.env`
- Initializes a basic Express HTTP server
- Exposes a root `GET /` endpoint returning a welcome message

---
